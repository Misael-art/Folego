# Ícones de fallback do seletor de prompts

`copy.svg` e `chevron-right.svg` são originais sem alterações de Tabler Icons,
distribuídos sob a licença MIT incluída em [LICENSE](LICENSE).
Fonte: https://github.com/tabler/tabler-icons, `icons/outline/`, obtida em 02/11/2026.
São usados quando o tema nativo não fornece `edit-copy`/`go-next`.
A máscara monocromática segue o helper de ícones já usado no Fôlego.
